The Natural style downloads Poly Haven assets to ignored `public/assets/natural/`.
Run `node scripts/natural-assets.mjs` once; the manifest pins SHA-256 hashes.
Only JPEG textures and glTF model data are downloaded, with no executables or
runtime CDN requests. All Poly Haven assets below use CC0 1.0 Universal:
- Forest Ground 01: https://polyhaven.com/a/forrest_ground_01
