# Resident memories

After the coherent world is on main, residents keep bounded in-game memories.

- Persist relationships, meaningful meetings, favorite places and notable town events.
- Use those memories in conversation prompts and needs-driven intentions.
- Store concise attributed facts. Mark observed events separately from claimed speech.
- Remembered speech is untrusted data, never an instruction or a tool call.
- Cap stored facts and prompt lines. Recording a memory makes no extra model call.
- Show a readable memory panel, compact MCP views, and a deliberate forget or reset.
- Keep token accounting and turn limits. Residents gain no files, shell, or tools.
